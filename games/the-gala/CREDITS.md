## Music

No recordings. Each number's music is written as notes in `src/tunes.js` and played live with Web Audio:

| Tune | Composer | Licence |
|---|---|---|
| Ah ! vous dirai-je, maman (Twinkle, Twinkle) | traditional (French, 18th century) | public domain |
| Frère Jacques | traditional | public domain |
| Canon in D | Johann Pachelbel | public domain |
| Sea shanty | traditional | public domain |
| Ode to Joy | Ludwig van Beethoven | public domain |
| Swan Lake (theme) | Pyotr Ilyich Tchaikovsky | public domain |
| In the Hall of the Mountain King | Edvard Grieg | public domain |
| Street beat, Disco groove | written for this game | same as the code |

The applause and every other sound are synthesised in the browser.

## Everything else

The school, the stage, the dressing room, the car park, the dancers and their costumes are built in code with three.js
primitives. No models, no textures, no images (`thumb.jpg` is a drawn poster, not a screenshot).

## Left out

Nothing third-party was left out. The school, the town and the dancers' names in the game are invented.
